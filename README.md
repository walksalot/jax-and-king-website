## How to Edit This Website

Everything is in one file: `index.html`. Check out the **Getting Started Guide** (PDF above) for step-by-step instructions with three options:

1. **Edit on GitHub** — make quick text changes right in your browser
2. **Use Claude.ai** — describe changes in plain English and get updated code
3. **Use Claude Code** — a terminal tool for hands-on ongoing work

Any changes you commit to this repository will automatically update the live website within 1–2 minutes.
